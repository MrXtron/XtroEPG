## 🚀 Quick Start

Add EPG to your IPTV playlist:

```m3u
#EXTM3U tvg-url="https://mrxtron.github.io/XtroEPG/epg.xml.gz"
#EXTINF:-1 tvg-id="channel-id" tvg-name="Channel Name" tvg-logo="logo-url", Channel Name
stream-url-here
```
